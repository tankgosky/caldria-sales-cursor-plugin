# Inbox Reply Drafting

1. Read support Gmail during business hours and sync each new prospect message once using its Gmail message ID.
2. Classify it as opt-out, wrong contact, bounce, interested, question, or quote request.
3. Suppress opt-outs immediately; do not prepare follow-up outreach for them.
4. Preserve the Gmail thread ID and create any response with `save_message_draft`.
5. Never send, approve, or promise final pricing, delivery, payment terms, inventory, or savings.
