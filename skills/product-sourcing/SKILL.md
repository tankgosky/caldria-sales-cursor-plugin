# Product Sourcing

1. Read pending quote requests and find multiple independently verifiable supplier candidates.
2. Record supplier, product URL, country, MOQ, unit cost and currency, freight and duty assumptions, lead time, evidence, and confidence.
3. Label missing, estimated, stale, or conflicting values explicitly.
4. Never log in as the customer, contact a supplier, submit a form, select a final supplier, or place an order.
5. Save candidates with `upsert_sourcing_candidate` and return an evidence-linked comparison.
